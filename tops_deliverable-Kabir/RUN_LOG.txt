  TOPS 2026 -- language-guided grasping with compliant control
  =========================================================

  FIRST TIME, in this order:
    make doctor        check what system packages are missing
    make deps          install the missing ones (asks for sudo)
    make build         compile the workspace            (~1-2 min)
    make test          run every unit test              (~1 min)
    make verify        prove the statistics pipeline works, no robot

  SEE IT WORK:
    make view          the arm in RViz, sliders, no physics
    make watch         ONE full grasp in Gazebo, start to finish
    make run           bring the system up and leave it up

  PRODUCE THE RESULTS:
    make trials        the full 120-trial battery         (~1-2 h)
    make trials-quick  a 24-trial smoke test              (~15 min)
    make analyse       turn the trial CSV into the report tables
    make plots         graphs from the full AND the quick CSV -> results/figures/
                       (trials / trials-quick also plot automatically)

  HOUSEKEEPING:
    make urdf          print the expanded robot model
    make topics        list what is running (system must be up)
    make clean         delete build output
    make clean-results delete recorded trial data, reports and figures

  Options (append to any run/trial target):
    CONTROLLER=impedance|admittance|baseline   (now: impedance)
    REGIME=clean|sensor_noise|calibration|displacement  (now: clean)
    SEED=<int>  PER_CELL=<int>  CSV=<path>
    Trial CSVs are APPENDED to, never overwritten: clear stale rows yourself.

  Example:  make watch CONTROLLER=baseline REGIME=calibration
            (the rigid controller against a miscalibrated camera --
             this is the failure the project exists to fix)
